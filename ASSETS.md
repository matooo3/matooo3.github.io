# Asset sources

- `assets/curiosity.webp`: generated specifically for this portfolio using the built-in Imagegen tool on 2026-09-14. Prompt: a single sculptural, intertwined orange matte ceramic loop, architectural studio photography on warm ivory, no text, no logos, 1536 × 1024. Generated PNG retained at the tool's original output location; this repository serves an optimized WebP.
- `assets/mylifegraph.webp`: actual light design-system golden from `MyLifeGraph/MyLifeGraph`, `apps/mobile/test/goldens/visual-system-light-desktop.png`. The visual explicitly says Design System; this is not presented as a live production screenshot.
- `assets/pencil2pixel.webp` and `assets/pencil-sketch.webp`: actual project examples from `matooo3/Pencil2Pixel`, `examples/out_sketch_airplane8.png` and `examples/airplane_sketch.png`.
- NutriPilot and Yapp AI panels are HTML/CSS concept demos with clearly labelled sample content: a meal planner/shopping list and a voice recorder/transcript. The bowl artwork and waveform are code-native illustrations, not real app screenshots.
- `assets/fonts/manrope-latin.woff2`: Manrope variable font from Google Fonts, SIL Open Font License; license in `assets/fonts/OFL.txt`.
- `assets/icons/*.svg`: Phosphor regular icons, MIT license in `assets/icons/LICENSE`. `archive-box.svg` is the official Phosphor `archive.svg` with a local filename alias. The source paths are otherwise unchanged.

All visible images, fonts and icons on the new portfolio are served locally. Archived third-party references remain as originally authored.
